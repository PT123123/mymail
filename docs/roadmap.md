# 路线图

「邮件客户端所需的所有功能」很长,按里程碑拆,每档都可独立发布。

## M0 —— 可用骨架(当前交付)

- [x] 双端工程骨架(Slint+Rust / Compose),可构建
- [x] 添加账户(含 QQ/163/Gmail/Outlook 预设、连接测试)
- [x] 文件夹列表(含层级、未读数)
- [x] 邮件列表(分页、未读高亮、星标)
- [x] 读信(MIME 解析;HTML 净化后 WebView 渲染;纯文本降级)
- [x] 写信 / 回信 / 全部回复 / 转发;附件添加与发送
- [x] 附件查看(下载后用系统关联程序打开)
- [x] 标记已读/未读、星标、删除(移垃圾桶)、移动文件夹
- [x] 本地缓存(离线可见)、首次全量回填
- [x] IMAP IDLE 新邮件 → 系统通知
- [x] 密码加密存储(DPAPI / Android Keystore)

## M1 —— 日用完整度

- 搜索:本地 FTS5 + 服务器 IMAP SEARCH 双通道
- 会话线程视图(按 References/Subject 聚合)
- 草稿:自动保存到服务器 Drafts、恢复编辑
- 多身份 / 签名管理
- 通知细化(按文件夹静音)、Windows 托盘与后台驻留
- 正文缓存 LRU、深浅色主题打磨、垃圾箱/垃圾邮件文件夹语义
- 批量操作(多选、全部已读)

## M2 —— 账户与自动化

- OAuth2(XOAUTH2):Gmail / Outlook / M365 基本认证替代方案
- POP3 账户支持
- 客户端收信规则(过滤、自动移动、自动标记)
- 联系人:本地地址簿 + 发信自动补全;CardDAV
- 配置导出/导入(跨设备迁移账户)
- 归档(All Mail)与批量归档

## M3 —— 高级

- CONDSTORE / QRESYNC 快速同步
- S/MIME 验签;OpenPGP(参考 Thunderbird 的 RNP 方案)
- Android 桌面小部件、快捷磁贴
- 统一收件箱(多账户聚合视图)
- 模板/稍后发送/定时发送

## M4 —— 打磨与分发

- i18n(当前 UI 为中文硬编码,先功能后本地化)
- 无障碍(读屏、键盘导航、大字号)
- 崩溃上报与诊断包
- 分发:Windows MSIX/商店包;Android 各应用商店
